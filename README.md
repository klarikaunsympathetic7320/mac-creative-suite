## ❓ Troubleshooting  
If something doesn’t work, try these simple fixes before contacting support:  

**Issue: The app won’t start after double-clicking.**  
- Make sure you’ve fully **extracted** the zip. Running the app from inside the compressed folder won’t work.  
- Right-click the `.exe` file → **Properties** → check “Unblock” if the file came from the internet and Windows blocked it.  

**Issue: A security warning pops up.**  
- This is normal for downloaded apps. Click **“More info”** → **“Run anyway”** if prompted by Windows SmartScreen. The file is safe.  

**Issue: The app looks blurry or too small.**  
- Right-click the `.exe` file → **Properties** → **Compatibility** tab → check **“Override high DPI scaling behavior”** → choose **“Application”** from the dropdown.  

**Issue: I lost my project files.**  
- The app auto-saves in a folder named `mac-creative-suite-backups` next to the application. Look there for recent `.mcs` files.  

**Issue: Can’t find the extracted folder.**  
- Search for `mac-creative-suite` in the Windows search bar (bottom left). Click the folder icon that appears.
